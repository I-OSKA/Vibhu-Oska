# Unity Assets

## Structure

```
Assets/
├── Scenes/                ← Unity scenes
├── Scripts/               ← C# MonoBehaviour scripts
├── Prefabs/               ← Reusable GameObjects
├── Materials/             ← Shader materials
├── Models/                ← 3D models
├── Textures/              ← Image textures
└── Audio/                 ← Sound files
```

## WebSocket Integration

Unity connects to `ws://localhost:8100/ws` for real-time communication with Vibhu-Oska backend.

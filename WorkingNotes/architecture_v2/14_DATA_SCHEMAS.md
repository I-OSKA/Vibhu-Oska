**Version**: 2.0  
**Status**: Phase 0 — Documentation Complete  
**Authority**: ParaCore (Supreme) → All Cores  
**Scope**: All data structures, checkpoint formats, and interface schemas

## Overview

This document defines **every data schema** used across the Vibhu-Oska system — from raw scraped data to checkpoint dictionaries, specialist interfaces, intent classification output, and training pipelines. All schemas use Python `dataclass` and `TypedDict` definitions for runtime validation and IDE support.

## 1. Corpus Format Specifications (Query/Response Pairs)

The fundamental training unit across all specialists and the SARA.

### 1.1 Raw Corpus Pair

```python
from dataclasses import dataclass, field
from typing import Optional, List, Dict, Any
from enum import Enum

class Difficulty(Enum):
    EASY = "easy"
    MEDIUM = "medium"
    HARD = "hard"
    EXPERT = "expert"

class SourceType(Enum):
    MANUAL = "manual"           # Human-written
    SYNTHETIC = "synthetic"     # Generated by CognitionCore
    SCRAPED = "scraped"         # Extracted from documentation
    DISTILLED = "distilled"     # Distilled from SARA
    RL_GENERATED = "rl_generated"  # From EvolutionCore RL loop

@dataclass
class CorpusPair:
    """Single query/response training pair."""
    query: str                                          # User prompt / question
    response: str                                       # Expert answer / code
    domain: str                                         # "coding" | "realworld" | "existing"
    subdomain: str                                      # "python" | "excel" | "data" | etc.
    source: SourceType                                  # Origin of this pair
    difficulty: Difficulty = Difficulty.MEDIUM
    metadata: Dict[str, Any] = field(default_factory=dict)
    # metadata may include:
    #   "language": "python" (for coding domain)
    #   "test_cases": [...] (for coding pairs)
    #   "citations": [...] (for knowledge domain)
    #   "corpus_category": "basics" | "stdlib_async" | etc.
    #   "quality_score": 0.0-1.0 (human or auto-rated)
    #   "tokens_estimated": int (pre-tokenized count)
    pair_id: Optional[str] = None                       # Unique ID for dedup
    created_at: Optional[float] = None                  # Unix timestamp
```

### 1.2 Serialized Corpus Pair (Storage Format)

```python
@dataclass
class CorpusPairSerialized:

    diff: str        # difficulty
    meta: Dict[str, Any] = field(default_factory=dict)

    ts: Optional[float] = None
```

### 1.3 Corpus File Structure

```
Backend/Core/SpecializedCore/{Domain}/{Specialist}/corpus/
├── basics.txt                  # Query/Response pairs, one per block
├── advanced.txt                # Separated by topic category
├── corpus.jsonl                # JSONL format (one JSON object per line)
├── corpus.train.txt            # 90% split for training
├── corpus.val.txt              # 10% split for validation
└── metadata.json               # Corpus statistics
```

## 2. Checkpoint Dict Structures

Every model type saves checkpoints with a standardized dictionary structure.

### 2.1 SARA Checkpoint (CognitionCore)

```python
from typing import Optional, List, Dict, Any
import torch

@dataclass
class SaraGPTCheckpoint:
    """Checkpoint dict for SARA (CognitionCore)."""
    # Model state
    model_state_dict: Dict[str, torch.Tensor]           # Full model weights
    optimizer_state_dict: Dict[str, Any]                 # AdamW optimizer state
    scheduler_state_dict: Optional[Dict[str, Any]] = None  # LR scheduler

    # Training state
    epoch: int = 0
    step: int = 0
    global_step: int = 0
    best_loss: float = float('inf')
    best_accuracy: float = 0.0

    # Hyperparameters
    config: Dict[str, Any] = field(default_factory=lambda: {
        "lr": 1e-4,
        "batch_size": 8,
        "warmup_epochs": 5,
        "max_seq_len_schedule": [128, 256, 512],
        "gradient_accumulation_steps": 4,
        "max_grad_norm": 0.5,
        "weight_decay": 0.01,
    })

    # Metrics history
    train_loss_history: List[float] = field(default_factory=list)
    val_loss_history: List[float] = field(default_factory=list)
    accuracy_history: List[float] = field(default_factory=list)
    perplexity_history: List[float] = field(default_factory=list)
    learning_rate_history: List[float] = field(default_factory=list)

    # Current epoch metrics
    current_train_loss: float = 0.0
    current_val_loss: float = 0.0
    current_accuracy: float = 0.0
    current_perplexity: float = 0.0

    # NaN tracking
    nan_detected: bool = False
    nan_step: Optional[int] = None
    inf_detected: bool = False
    inf_step: Optional[int] = None
    emergency_checkpoint: bool = False

    # System info
    vram_usage_mb: float = 0.0
    training_time_seconds: float = 0.0
    timestamp: float = 0.0
    version: str = "2.0"

    def to_dict(self) -> Dict[str, Any]:
        """Convert to saveable dict."""
        return {k: v for k, v in self.__dict__.items() if not k.startswith('_')}

    @classmethod
    def from_dict(cls, d: Dict[str, Any]) -> 'SaraGPTCheckpoint':
        """Load from saved dict."""
        return cls(**{k: v for k, v in d.items() if k in cls.__dataclass_fields__})
```

## 3. Specialist Capabilities Manifest Format

Every specialist declares its capabilities via this manifest, loaded at registration time.

```python
from dataclasses import dataclass, field
from typing import List, Dict, Optional, Any
from enum import Enum

class SupportLevel(Enum):
    NONE = "none"
    BASIC = "basic"
    FULL = "full"
    EXPERT = "expert"

@dataclass
class SpecialistCapabilities:
    """
    Static capability manifest for a specialist.
    Loaded once at registration, queried by Orchestrator and BackupCore.
    """
    # Identity
    domain: str                     # "coding" | "realworld" | "existing"
    subdomain: str                  # "python" | "excel" | "data" | etc.
    display_name: str               # "PythonCore" | "ExcelCore" | etc.

    # Model info
    model_params: int               # 15_000_000
    model_arch: str                 # "gpt2" | "transformer" | "custom"
    vram_mb_fp16: int               # 1200
    vram_mb_4bit: int               # 300
    load_time_seconds: float        # 2.5

    # Capabilities
    capabilities: List[str]         # ["code_gen", "debugging", "explanation"]
    supports_streaming: bool = False
    supports_tools: bool = False
    supports_multi_turn: bool = False
    supports_citations: bool = False

    # Context limits
    max_context_tokens: int = 2048
    max_output_tokens: int = 1024
    supports_system_prompt: bool = True

    # Language support (coding specialists only)
    supported_languages: List[str] = field(default_factory=list)

    # Corpus info
    corpus_size: int = 0            # Number of Q&A pairs
    corpus_categories: List[str] = field(default_factory=list)

    # Checkpoint paths
    checkpoint_path: Optional[str] = None
    tokenizer_path: Optional[str] = None
    config_path: Optional[str] = None

    # Dependencies
    dependencies: List[str] = field(default_factory=list)
    # Other specialists or cores this one depends on

    # Quality metrics (updated after training)
    validation_accuracy: float = 0.0
    benchmark_score: float = 0.0
    last_trained: Optional[float] = None

    # Versioning
    version: str = "1.0"
    min_compatible_version: str = "1.0"

    def matches_query(self, domain: str, subdomain: Optional[str] = None) -> float:
        """Compute relevance score for a given query domain/subdomain."""
        if self.domain != domain:
            return 0.0
        if subdomain and self.subdomain != subdomain:
            return 0.5  # Partial match (same domain, different subdomain)
        return 1.0

    def can_handle(self, required_capabilities: List[str]) -> bool:
        """Check if this specialist has all required capabilities."""
        return all(cap in self.capabilities for cap in required_capabilities)
```

```python
from dataclasses import dataclass, field
from typing import List, Dict, Optional, Any

@dataclass
class ScrapedItem:
    """Single item extracted by a scraper. Written as one JSON line."""
    url: str                           # Source URL
    title: str                         # Page/section title
    content: str                       # Extracted text content
    content_type: str                  # "documentation" | "tutorial" | "reference" | "example"
    domain: str                        # "coding" | "realworld"
    subdomain: str                     # "python" | "excel" | etc.
    source_name: str                   # "python_docs" | "mdn" | "cppreference"
    metadata: Dict[str, Any] = field(default_factory=dict)
    # metadata may include:
    #   "language": "python"
    #   "version": "3.12"
    #   "tags": ["async", "asyncio"]
    #   "heading_hierarchy": [" asyncio", "Basics", "Coroutines"]
    #   "code_blocks": [{"lang": "python", "code": "..."}]
    #   "links": ["https://..."]
    #   "last_modified": "2024-01-15"
    scraped_at: float = 0.0
    content_hash: str = ""             # SHA256 for dedup

    def to_jsonl_line(self) -> str:
        """Serialize to a single JSON line."""
        import json
        return json.dumps({
            "url": self.url,
            "title": self.title,
            "content": self.content,
            "content_type": self.content_type,
            "domain": self.domain,
            "subdomain": self.subdomain,
            "source_name": self.source_name,
            "metadata": self.metadata,
            "scraped_at": self.scraped_at,
            "content_hash": self.content_hash,
        }, ensure_ascii=False)

    @classmethod
    def from_jsonl_line(cls, line: str) -> 'ScrapedItem':
        """Deserialize from a JSON line."""
        import json
        d = json.loads(line)
        return cls(**d)


@dataclass
class JSONLDataset:
    """
    Complete JSONL dataset for a specialist's scraped data.
    Written to: Data/training/specialized/{Domain}/{Specialist}/corpus/raw.jsonl
    """
    domain: str
    subdomain: str
    items: List[ScrapedItem] = field(default_factory=list)

    def write_jsonl(self, path: str):
        """Write all items to a JSONL file."""
        with open(path, 'w', encoding='utf-8') as f:
            for item in self.items:
                f.write(item.to_jsonl_line() + '\n')

    @classmethod
    def read_jsonl(cls, path: str, domain: str = "", subdomain: str = '') -> 'JSONLDataset':
        """Read items from a JSONL file."""
        items = []
        with open(path, 'r', encoding='utf-8') as f:
            for line in f:
                line = line.strip()
                if line:
                    items.append(ScrapedItem.from_jsonl_line(line))

        if not items and domain:
            return cls(domain=domain, subdomain=subdomain, items=items)

        domain = domain or (items[0].domain if items else "")
        subdomain = subdomain or (items[0].subdomain if items else "")
        return cls(domain=domain, subdomain=subdomain, items=items)

    @property
    def stats(self) -> Dict[str, Any]:
        """Dataset statistics."""
        content_lengths = [len(item.content) for item in self.items]
        source_counts = {}
        for item in self.items:
            source_counts[item.source_name] = source_counts.get(item.source_name, 0) + 1

        return {
            "total_items": len(self.items),
            "avg_content_length": sum(content_lengths) / max(1, len(content_lengths)),
            "min_content_length": min(content_lengths) if content_lengths else 0,
            "max_content_length": max(content_lengths) if content_lengths else 0,
            "source_distribution": source_counts,
            "unique_urls": len(set(item.url for item in self.items)),
            "unique_hashes": len(set(item.content_hash for item in self.items if item.content_hash)),
        }
```

```python
class TokenizerVocab:

    """

    vocab: Dict[str, int] = field(default_factory=dict)

    # token_id -> Token mapping (auto-generated from vocab)

    # Special tokens

        "<pad>": 0,
        "<unk>": 1,
        "<bos>": 2,
        "<eos>": 3,
        "<sep>": 4,
        "<mask>": 5,
        "<cls>": 6,
        "<query>": 7,
        "<response>": 8,
        "<system>": 9,
        "<tool_call>": 10,
        "<tool_result>": 11,
    })

    # Tokenizer config
    vocab_size: int = 32000
    model_max_length: int = 2048
    tokenizer_class: str = "BPE"       # "BPE" | "WordPiece" | "Unigram" | "SentencePiece"
    normalization: str = "NFKC"        # Unicode normalization form
    lowercase: bool = False
    strip_accents: bool = False

    # BPE-specific
    bpe_merges: List[List[str]] = field(default_factory=list)
    # Merge rules: [["a", "b"], ["ab", "c"], ...]

    # Training metadata
    trained_on_pairs: int = 0           # Number of Q&A pairs used to train tokenizer
    trained_on_tokens: int = 0          # Total tokens in training data
    coverage_ratio: float = 0.0         # % of training tokens covered by vocab
    unknown_ratio: float = 0.0          # % of training tokens that are <unk>

    # Domain-specific tokens
    domain_tokens: List[str] = field(default_factory=list)
    # Tokens added for domain vocabulary:
    # Coding: ["def", "class", "import", "async", "await", "fn", "let", "pub", ...]
    # RealWorld: ["VLOOKUP", "INDEX", "MATCH", "systemd", "docker", "kubectl", ...]

    # File paths
    vocab_file: Optional[str] = None    # Path to vocab.json
    merges_file: Optional[str] = None   # Path to merges.txt (BPE)
    tokenizer_file: Optional[str] = None  # Full tokenizer serialization

    def build_inv_vocab(self):
        """Rebuild inverse vocabulary from vocab."""
        self.inv_vocab = {v: k for k, v in self.vocab.items()}

    def add_domain_tokens(self, tokens: List[str]):
        """Add domain-specific tokens to vocabulary."""
        next_id = max(self.special_tokens.values()) + 1
        for token in tokens:
            if token not in self.vocab:
                self.vocab[token] = next_id
                self.inv_vocab[next_id] = token
                next_id += 1
                self.domain_tokens.append(token)

    def get_token_id(self, token: str) -> int:
        """Get token ID, returning <unk> ID if not found."""
        return self.vocab.get(token, self.special_tokens["<unk>"])

    def get_token(self, token_id: int) -> str:
        """Get token string from ID."""
        return self.inv_vocab.get(token_id, "<unk>")

    offsets: Optional[List[tuple]] = None       # (start, end) char offsets

        }
```

## 10. Experience Buffer Schema

Format for EvolutionCore's prioritized experience replay.

```python
from dataclasses import dataclass, field
from typing import List, Dict, Optional, Any

@dataclass
class Experience:
    """Single experience in the RL replay buffer."""
    state: str                         # Input prompt/context
    action: str                        # Specialist's generated output
    reward: float                      # Computed reward
    next_state: Optional[str] = None   # Follow-up context (if any)
    done: bool = False                 # Episode terminated?
    metadata: Dict[str, Any] = field(default_factory=dict)
    # metadata may include:
    #   "domain": "coding"
    #   "subdomain": "python"
    #   "specialist": "python_core"
    #   "execution_time_ms": 150.0
    #   "security_violations": []
    #   "reward_components": {"syntax_valid": 1.0, "executes": 2.0, ...}

    # Priority (for prioritized replay)
    priority: float = 1.0
    sampling_probability: float = 0.0

    # Tracking
    experience_id: Optional[int] = None
    added_at: float = 0.0
    sampled_count: int = 0             # Times this was sampled for training

@dataclass
class ExperienceBatch:
    """Batch of experiences sampled from the buffer."""
    experiences: List[Experience]
    weights: List[float]               # Importance sampling weights
    indices: List[int]                 # Buffer indices (for priority update)

    def to_grpo_format(self) -> Dict[str, Any]:
        """Convert to format expected by GRPOTrainer."""
        return {
            "states": [e.state for e in self.experiences],
            "actions": [e.action for e in self.experiences],
            "rewards": [e.reward for e in self.experiences],
            "dones": [e.done for e in self.experiences],
            "weights": self.weights,
        }
```
